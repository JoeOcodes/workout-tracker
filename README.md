# Workout Tracker


## About
The workout tracker is intended to be a portfolio and learning project that simulates a real world fitness tracking application. The goal for the application is to allow users to easily record workouts, manage exercises, and view workout history.

## Tech Stack
- PostgreSQL 
- Express.js
- Node.js
- TypeScript (migration in progress)
- Drizzle ORM
